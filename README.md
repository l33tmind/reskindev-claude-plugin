# Reskindev for Claude

Reskindev (https://reskindev.com) is a freelance marketplace. This plugin lets you find and hire freelancers, or post and improve your own gigs, by chatting with Claude.

## Install

**Claude Code**

```
/plugin marketplace add l33tmind/reskindev-claude-plugin
/plugin install reskindev@reskindev
```

**Claude (claude.ai and the desktop app)**

Customize → Plugins → Add → Add marketplace → `l33tmind/reskindev-claude-plugin`, then install **reskindev**.

## What you get

- **Hire** (no sign-in): search gigs, compare prices, delivery time and reviews, read seller profiles. Ordering and payment happen on reskindev.com.
- **Sell** (sign in to Reskindev once): Claude asks simple questions, writes your gig in English and Bangla, builds Basic / Standard / Premium packages, suggests prices and prepares the thumbnails. Every gig is reviewed by Reskindev before it goes live.

Details: [plugins/reskindev/README.md](plugins/reskindev/README.md)

Prefer a plain connector? Add `https://reskindev.com/mcp` as a custom connector in Claude. Guide: https://reskindev.com/ai
